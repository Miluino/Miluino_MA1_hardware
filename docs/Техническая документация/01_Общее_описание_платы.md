# Miluino MA1: общее описание платы

## Назначение и состав

Miluino MA1 — проект отладочной платы на микроконтроллере К1986ВЕ92FI. Плата предоставляет разъёмы геометрии Arduino UNO и STMorpho, отдельный USB-C целевого микроконтроллера и встроенный программатор на STM32F103CBU6 с интерфейсом CMSIS-DAP. Механическая карта STMorpho ориентирована на NUCLEO-F103RB; совпадение положения контактов не означает электрическую совместимость любого готового шилда.

Основные функциональные узлы:

| Узел | Назначение |
|---|---|
| К1986ВЕ92FI | Исполняет пользовательскую программу, предоставляет GPIO, АЦП, ЦАП, таймеры, UART, SPI, I²C, CAN и USB Device. |
| STM32F103CBU6 | Аппаратная основа встроенного CMSIS-DAP: SWD/SWO, управление сбросом и питанием от USB-C DAP, опциональный VCP. |
| Arduino и STMorpho | Доступ к функциям К1986; часть контактов подключена напрямую, часть — через селекторы 0 Ом. |
| DAP_ROUTE и DBG_PORT_SEL | Выбирают внешнюю или локальную цель встроенного DAP и один из двух JTAG-портов К1986. |
| T-селектор питания | Выбирает один из трёх источников `+5V_TGT`: USB-C DAP, USB-C target или VIN после преобразователя. |
| Output Power | Включаемые прошивкой К1986 защищённые выходы 5 В и 3,3 В для Arduino и части STMorpho. |

Два микроконтроллера имеют раздельные шины `+3V3_DAP` и `+3V3_TGT` при общей GND. Гальванической изоляции между доменами нет. Сигнальные линии не гарантируют защиты от подпитки выключенного домена через выводы микроконтроллеров.

## Интерфейсы

| Интерфейс | Реализация и основное ограничение |
|---|---|
| USB-C DAP | Постоянный Device/UFP/Sink для STM32F103. Его VBUS питает DAP, защищённые выходы DAP и, при выборе T-селектором, локальную target. |
| USB-C target | Отдельный постоянный Device/UFP/Sink для К1986. Его VBUS поступает на T-селектор без дополнительного eFuse платы. |
| Arduino | Логические уровни GPIO — 3,3 В. Контакты +5V и +3V3 — защищённые выходы питания; VIN — вход внешнего питания. |
| STMorpho CN7/CN10 | Повторяют расположение контактов NUCLEO-F103RB, но содержат назначения К1986 и отдельные прямые контакты только для высокоомного контроля питания. |
| XP7 | Шестиконтактный SWD/SWO выход встроенного DAP на внешнюю target; контакт `EXT_VTREF` является входом опорного напряжения, а не выходом питания. |
| ARM Cortex Debug 10-pin | Вход внешнего отладчика на общую локальную DBG-шину; поддерживает SWD и четырёхпроводный JTAG. |
| XP5 | Сервисный SWD для прошивки и восстановления самого STM32F103. |

Используются только внешние устройства с совместимыми логическими уровнями 3,3 В. Контакты Arduino D4/D5 содержат логические сигналы CAN1_TX/CAN1_RX при нужной коммутации; для физической шины CAN необходим внешний трансивер. Отдельный Arduino ICSP не предусмотрен: SPI доступен через D10–D13 и STMorpho.

## Основные режимы

| Задача | Питание target | DAP_ROUTE | DBG_PORT_SEL | MODE[2:0] |
|---|---|---|---|---|
| Штатная отладка К1986 встроенным DAP | Один вход T-селектора | TARGET | A | 001 |
| Отладка К1986 встроенным DAP через JTAG_B/SWD | Один вход T-селектора | TARGET | B | 000 |
| Отладка К1986 внешним адаптером через ARM 10-pin | Один вход T-селектора | OFF | A или B | Соответственно 001 или 000 |
| Отладка внешней платы встроенным DAP | Питание внешней платы отдельно | EXTERNAL | OFF рекомендуется | Не влияет на внешнюю плату |
| Выключение локальной target | Джампер T-селектора снят | OFF | OFF рекомендуется | Любое |

MODE считывается при включении К1986. После его изменения требуется полное отключение и повторное включение питания `+3V3_TGT`; обычный nRESET нового режима не применяет. При питании target отдельно от DAP штатный тактовый сигнал `DAP_MCO` может отсутствовать: программа должна иметь путь запуска от внутреннего генератора либо следует установить альтернативный источник HSE.

## Статус исполнения

Документы описывают электрическую схему и предусмотренные варианты комплектации, а не результаты испытаний изготовленной платы. Номиналы, помеченные как предварительные, и параметры, зависящие от выбора конкретных компонентов, проверяются при разработке прототипа. Штатно не устанавливаемые элементы обозначены `DNP`; такие цепи не следует считать действующими в базовой комплектации.
